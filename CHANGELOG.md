# Changelog

All notable changes to tokenwatch will be documented here.

## [0.1.0] - 2026-05-05

### Added
- Initial release
- Phase 0: Monorepo scaffold with pnpm workspaces, TypeScript, ESLint, Prettier
- Phase 1: Log collector with JSONL watcher, parser, SQLite storage
- Phase 2: Analytics engine with burn rate, cost aggregation, session ranking
- Phase 3: REST + WebSocket API server
- Phase 4: React web dashboard with real-time charts
- Phase 5: Terminal UI (TUI) with Ink
- Phase 6: VS Code extension with status bar token meter
- Phase 7: Team mode for multi-user aggregation
- Phase 8: CI/CD, GitHub Actions, report CLI
